#+TITLE: Emacs Configuration
#+STARTUP: overview

Loaded by: [[file:~/.emacs.d/init.el][init.el]]

Configuration is split into domain files, all in the same directory as
this file (~/.emacs.d/config/, symlinked from the distro source).

- [[file:core.org][core.org]] — Emacs base: packages, UI, font, version control, protected files, startup sync
- [[file:org-setup.org][org-setup.org]] — Org mode: agenda, capture, tags, clocking, export, LaTeX, graphics
- [[file:gptel-setup.org][gptel-setup.org]] — AI: gptel backends, tools, Claude Executor, workspace context, system prompt
- [[file:wiki-setup.org][wiki-setup.org]] — LLM-maintained Emacs-knowledge wiki (Karpathy pattern) — directive, helpers (=C-c n I/M/U/Q/L=), capture template
- [[file:org-apple-reminders-setup.org][org-apple-reminders-setup.org]] — Apple Reminders via [[https://github.com/deno1011/org-apple-reminders][org-apple-reminders]] Paket (JXA/osascript, kein CLI) — /nur macOS/

To apply changes after editing a sub-file, run =M-x org-babel-tangle= in that file,
then =M-x load-file= on the generated =.el= file (or restart Emacs).

* Bootstrap

#+begin_src elisp :tangle yes
;; bootstrap.org MUST load first: it unlocks Bitwarden, fetches the
;; user's GitHub identity, clones / pulls the private data repo,
;; generates starter content where files are missing, and populates
;; API-key env vars. Every other split file below depends on at least
;; one of those (org-setup.org needs ~/emacs/data/org/, gptel-setup.org
;; needs the API-key env vars, wiki-setup.org needs ~/emacs/wiki/emacs/).
(defvar my/config-split-files
  '("bootstrap.org" "core.org" "org-setup.org" "gptel-setup.org" "wiki-setup.org"))
(when (eq system-type 'darwin)
  (add-to-list 'my/config-split-files "org-apple-reminders-setup.org" t))

;; Config files are symlinked into ~/.emacs.d/config/ by install.sh. If a
;; split file is missing, the right fix is `bash install.sh` (which
;; re-syncs the symlink), not a silent network fetch — so this loop only
;; loads what's actually on disk and logs a clean error otherwise.
(dolist (f my/config-split-files)
  (let ((path (expand-file-name f my/config-dir)))
    (if (file-exists-p path)
        (condition-case err
            (org-babel-load-file path)
          (error (message "CONFIG LOAD ERROR (%s): %s" f err)))
      (message "CONFIG MISSING: %s — try `bash ~/emacs-mac-setup-src/install.sh`" path))))
#+end_src

* GTD Overlay

Loads the GTD configuration from =~/emacs/data/org/gtd-config.el=.
Runs AFTER =org-setup.org= so it overrides the norang defaults.

#+begin_src elisp :tangle yes
(let ((gtd-config (expand-file-name "data/org/gtd-config.el" my/data-dir)))
  (when (file-exists-p gtd-config)
    (condition-case err
        (load gtd-config nil nil t)
      (error (message "GTD CONFIG LOAD ERROR: %s" err)))))
#+end_src
