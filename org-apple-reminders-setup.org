#+TITLE: org-apple-reminders Setup
#+STARTUP: overview

Loads and configures the [[https://github.com/deno1011/org-apple-reminders][org-apple-reminders]] package for bidirectional
sync between org-mode and Apple Reminders.

macOS only (JXA/osascript required).

* Installation and auto-update

Installs =org-apple-reminders= from GitHub via =package-vc-install= (Emacs 29+).
After installation, schedules a silent background update check 10 seconds after
Emacs becomes idle — so the package is always at the latest =main= commit on the
next startup, without slowing down init.

Once the package is available on MELPA, replace this block with =:ensure t= in
the use-package form below and remove the =package-vc-install= call.

#+begin_src emacs-lisp :tangle yes
(when (eq system-type 'darwin)
  (unless (package-installed-p 'org-apple-reminders)
    (package-vc-install
     '(org-apple-reminders
       :url "https://github.com/deno1011/org-apple-reminders"
       :branch "main")))
  ;; Pull latest main asynchronously at startup — non-blocking, silent if offline.
  ;; Updated code is active from the next Emacs session.
  (when-let* ((lib (locate-library "org-apple-reminders"))
              (dir (file-name-directory lib)))
    (make-process
     :name "org-ar-update"
     :command (list "git" "-C" dir "pull" "--rebase" "--quiet")
     :noquery t
     :sentinel (lambda (proc _)
                 (when (and (not (process-live-p proc))
                            (zerop (process-exit-status proc)))
                   (message "org-apple-reminders: updated — restart to apply"))))))
#+end_src

* Configuration

Configures the package as recommended in the README:

- =org-apple-reminders-sync-file= :: The org file mirrored with Apple Reminders.
  Created automatically on first sync.
- =org-apple-reminders-auto-sync-interval= :: Seconds between background pulls
  (default: 300 = 5 minutes).
- =org-apple-reminders-setup= :: Starts the timer, registers org-agenda and
  org-capture. Must be called once.

#+begin_src emacs-lisp :tangle yes
(when (eq system-type 'darwin)
  (use-package org-apple-reminders
    :ensure nil
    :config
    (setq org-apple-reminders-sync-file "~/org/reminders.org")

    (org-apple-reminders-setup)

    ;; Global key bindings — work from any buffer
    (global-set-key (kbd "C-c r d") #'org-apple-reminders-dashboard)
    (global-set-key (kbd "C-c r R") #'org-apple-reminders-sync)
    (global-set-key (kbd "C-c r a") #'org-apple-reminders-add)
    (global-set-key (kbd "C-c r l") #'org-apple-reminders-show-lists)
    (global-set-key (kbd "C-c r L") #'org-apple-reminders-create-list)

    ;; Org-mode key bindings
    (with-eval-after-load 'org
      (define-key org-mode-map (kbd "C-c r p") #'org-apple-reminders-push-heading))))
#+end_src
