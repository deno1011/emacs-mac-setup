#+TITLE: Emacs Configuration
#+STARTUP: overview

Configuration is split across three files — edit them directly:

- [[file:core.org][core.org]] — Emacs base: packages, UI, font, version control, protected files, startup sync
- [[file:org-setup.org][org-setup.org]] — Org mode: agenda, capture, tags, clocking, export, LaTeX, graphics
- [[file:gptel-setup.org][gptel-setup.org]] — AI: gptel backends, tools, Claude Executor, workspace context, system prompt

To apply changes after editing a sub-file, run =M-x org-babel-tangle= in that file,
then =M-x load-file= on the generated =.el= file (or restart Emacs).
