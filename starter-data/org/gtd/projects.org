#+TITLE: Projects
#+FILETAGS: :project:
#+STARTUP: overview

Anything requiring more than one action step. Each project gets its
own heading; subtasks beneath it. A healthy project has:

- A clearly defined "done" outcome
- At least one =NEXT= or =TODO= action
- Optional tags for context (@home, @office, …)

Projects without a NEXT action surface as "Stuck Projects" in the
Weekly Review (=C-c a r=).
