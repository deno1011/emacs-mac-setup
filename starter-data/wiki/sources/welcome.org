* Key points extracted from the source

- A persistent, structured knowledge base is qualitatively different
  from RAG over chunks.
- Wiki pages get *interlinked* — links compound the value of each
  ingest.
- The LLM is the maintainer; the user provides raw sources and
  questions.
- Type discipline (entity / concept / source / comparison / overview)
  prevents the wiki from devolving into one long document.
