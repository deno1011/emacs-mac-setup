#+TITLE: Emacs
#+FILETAGS: :entity:editor:

* Summary

Emacs is an extensible, self-documenting text editor developed since
the mid-1970s, currently maintained by the GNU Project. Its
extensibility — every visible behaviour is implemented in Emacs Lisp
and rebindable at runtime — makes it as much a Lisp environment as a
text editor. This distro ships [[https://github.com/d12frosted/homebrew-emacs-plus][emacs-plus]] (GNU Emacs 30+ with
native compilation, a modern macOS icon, and a few macOS-specific
patches).

* Why it matters to this distro

Emacs is the substrate every other layer here sits on: org-mode for
the agenda and the wiki, gptel for the AI chat, org-roam for the
wiki's ID-based linking. The choice of Emacs (vs Obsidian, vs VS Code
with plugins) is what makes a single literate config file load all of
these into one keyboard-driven environment with no IPC.

* In this install

- ~/.emacs.d -> the distro's emacs.d/ (symlink, read-only from your
  perspective)
- Config split: ~core.org~, ~org-setup.org~, ~gptel-setup.org~,
  ~wiki-setup.org~, ~org-apple-reminders-setup.org~
- Init-phase tuning in ~early-init.el~ (GC threshold)
- Per-Mac secrets in ~~/.emacs.d/secrets.el~ (untracked)
