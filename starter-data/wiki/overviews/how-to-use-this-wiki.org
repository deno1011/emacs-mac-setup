#+TITLE: How to use this wiki
#+FILETAGS: :overview:wiki:tour:

* Summary

This page is the entry point if you're poking at the wiki for the
first time. It explains the five-folder layout, the page-type
discipline, the helpers under =C-c n=, and the org-roam ID-link
mechanic. Five minutes here saves an hour of "where do I put this".

* The five folders

| Folder         | Filetag         | What goes here                        | Example              |
|----------------+-----------------+---------------------------------------+----------------------|
| =sources/=     | =:source:=      | One page per raw doc you ingested     | [[id:2b1e1720-89d9-46a3-921d-14b51fd224f5][Welcome]] |
| =entities/=    | =:entity:=      | Discrete things (tools, packages, people) | [[id:62025262-2711-413a-8fba-97eceda41ad4][Emacs]] |
| =concepts/=    | =:concept:=     | Abstract ideas, patterns, models       | [[id:2714125c-2dc8-447e-869c-0a3f35916903][LLM Wiki Pattern]] |
| =comparisons/= | =:comparison:=  | A-vs-B contrast pages                  | [[id:fd4af44a-5fba-44e7-b539-a26f7b5f0ebd][LLM Wiki vs RAG]] |
| =overviews/=   | =:overview:=    | Synthesis pages (plans, tours, indexes) | this page          |

The =raw/= folder holds the original docs you ingested — *never*
edited after the initial save. The agent reads from =raw/= and writes
*about* it into =sources/=.

* The page format

Every page has, in this order:

1. =:PROPERTIES: :ID: <uuid>= drawer — required for org-roam linking
2. =#+TITLE:= — human-readable title
3. =#+FILETAGS: :<type>:<topic-tags>:=
4. A =* Summary= section (1–3 paragraphs, never an empty stub)
5. Type-specific content sections
6. =* Cross-Linkage= — bullets linking to peer pages
7. =* Related= — external links, books, papers

* The =C-c n= helpers

Defined in =~/.emacs.d/config/wiki-setup.org=. Common ones:

- =C-c n f=  ::  find / create an org-roam node (uses =index.org=)
- =C-c n i=  ::  insert a link to another node
- =C-c n I=  ::  *ingest* a raw source (URL or region) — the LLM
                 creates a =:source:= page and EXTEND any related
                 entities / concepts
- =C-c n Q=  ::  query the wiki via gptel
- =C-c n L=  ::  lint the wiki (find orphan pages, broken links)
- =C-c n B=  ::  ingest the current buffer as raw

Customize the directive that runs at ingest in
=~/.emacs.d/config/wiki-setup.org= — search for ~wiki-maintainer~.

* index.org and log.org

- =index.org= is the *catalog*. Every new page should get a bullet
  added under the matching section (Sources / Entities / Concepts /
  Comparisons / Overviews). The agent reads this first to find pages.
- =log.org= is the *timeline*. Every ingest, refactor, or lint
  appends an entry: =** [YYYY-MM-DD] <op> | <subject>=. Greppable.
