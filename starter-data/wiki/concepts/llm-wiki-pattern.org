#+TITLE: LLM Wiki Pattern
#+FILETAGS: :concept:wiki:llm:

* Summary

The LLM Wiki pattern, proposed by Andrej Karpathy
([[https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f][original gist]]), is a way of building a personal knowledge base where
a Large Language Model incrementally ingests raw sources and produces
a structured, interlinked collection of markdown/org-mode pages.

The key distinction from RAG is *persistent synthesis*: the wiki holds
the LLM's distilled understanding of a domain across many sources, not
just a vector index over chunks. New ingests EXTEND existing pages
rather than appending another opaque document. Cross-references
between pages compound the value the more the wiki grows.

* Why it matters

For an Emacs user with org-roam and gptel, the pattern fits naturally:
- Each page is an org-roam node with an =:ID:= for stable linking.
- Page types (entity / concept / source / comparison / overview)
  follow a strict schema so the LLM knows where to put new material.
- An =index.org= catalog and =log.org= timeline let the LLM
  bootstrap context cheaply on each new turn.
- Capture happens via familiar org-mode workflows; the LLM is just
  another writer.

* How this distro ships it

The starter wiki at =~/emacs/wiki/= contains five sample pages
(this one is the =:concept:= example). The ingest helpers under
=C-c n= prefix (defined in =~/.emacs.d/config/wiki-setup.org=) wire a
gptel directive that knows the schema. Run =C-c n I= with a region or
URL to ingest a new source.
