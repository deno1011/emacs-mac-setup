* Repository Roles

- =~/emacs= is the private live Emacs-plus runtime repo.
- =~/emacs/config/gptel-setup.org= is only the loader for the AI package.
- =~/gptel-agent-runtime= is the standalone package development repo.
- =~/emacs-mac-setup= is the installer/bootstrap/template repo.

* Installation and Auto-Update

Installs =gptel-agent-runtime= from GitHub via =package-vc-install= (Emacs 29+).
After installation, schedules a silent background update check 10 seconds after
Emacs becomes idle. Updated package code is active from the next Emacs session.

For day-to-day development use the =main= branch. The =stable= branch currently
points to the same version and can later become the slower-moving install target.

Once the package is available on MELPA, replace this block with =:ensure t= in
the use-package form below and remove the =package-vc-install= call.

#+begin_src emacs-lisp :tangle yes
(unless (package-installed-p 'gptel-agent-runtime)
  (package-vc-install
   '(gptel-agent-runtime
     :url "https://github.com/deno1011/gptel-agent-runtime"
     :branch "main")))

;; Pull latest main asynchronously at startup. This is non-blocking and silent
;; if offline. Updated code becomes active from the next Emacs session.
(when-let* ((lib (locate-library "gptel-agent-runtime"))
            (dir (file-name-directory lib)))
  (run-with-idle-timer
   10 nil
   (lambda (update-dir)
     (make-process
      :name "gptel-agent-runtime-update"
      :command (list "git" "-C" update-dir "pull" "--rebase" "--quiet")
      :noquery t
      :sentinel (lambda (proc _)
                  (when (and (not (process-live-p proc))
                             (zerop (process-exit-status proc)))
                    (message "gptel-agent-runtime: updated — restart to apply")))))
   dir))
#+end_src

* Configuration

The package currently carries the extracted implementation and its compatibility
names. It expects the main Emacs config to have already defined runtime paths
such as =my/data-dir=, which happens in =~/.emacs.d/init.el= before
=config.org= loads this file.

The package configures:

- gptel providers and local backends
- active Ollama model detection, with Qwen fallback
- local-model directives
- web helpers
- response execution and inline image rendering hooks
- gptel tools
- workspace context
- experimental planner loop

#+begin_src emacs-lisp :tangle yes
(use-package gptel-agent-runtime
  :ensure nil
  :demand t
  :config
  (message "gptel-agent-runtime loaded from package"))
#+end_src
