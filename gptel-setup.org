This setup file intentionally stays small. The reusable AI implementation lives
in the standalone package repository:

[[https://github.com/deno1011/gptel-agent-runtime][deno1011/gptel-agent-runtime]]

The setup repository owns first-install choices: which package branch is used,
which local provider is preferred, and which local model should be ready after a
fresh Mac setup. The runtime package owns agent behavior, tools, memory, routing,
and model-neutral execution.

* Repository Roles

- =~/emacs-mac-setup= is the installer/bootstrap/template repo.
- =~/emacs= or =~/emacs-data= is the private live Emacs runtime repo.
- =~/gptel-agent-runtime= is the standalone package development repo.
- =~/.emacs.d/config-readonly= is the generated readonly load target.

* Local Model Defaults

The macOS setup script installs Ollama, starts the server, and pulls the default
model before Emacs starts when the corresponding options in
=setup-emacs-mac.conf= are enabled. This Emacs-side block selects that same model
inside gptel once the runtime package is loaded.

Defaults:

- provider: Ollama
- model: =qwen2.5-coder:7b=
- model label in =C-c M=: =Qwen 2.5 Coder 7B (Ollama)=

#+begin_src emacs-lisp :tangle yes
(defvar my/gptel-agent-package-branch "main"
  "Git branch used for `gptel-agent-runtime' during package-vc installation.
Use \"stable\" for release installs and a feature branch for branch testing.")

(defvar my/gptel-setup-default-ollama-model 'qwen2.5-coder:7b
  "Default Ollama model selected after `gptel-agent-runtime' loads.")

(defvar my/gptel-setup-default-ollama-label "Qwen 2.5 Coder 7B (Ollama)"
  "Display label for `my/gptel-setup-default-ollama-model'.")

(defvar my/gptel-setup-ollama-models-directory nil
  "Optional Ollama model directory.
When non-nil, the runtime starts Ollama with OLLAMA_MODELS pointing here.")
#+end_src

* Package Installation and Auto-Update

Installs =gptel-agent-runtime= from GitHub via =package-vc-install= (Emacs 29+).
After installation, schedules a silent background update check 10 seconds after
Emacs becomes idle. Updated package code is active from the next Emacs session.

The public install branch should normally be =stable=. Branch-specific setup
branches may set =my/gptel-agent-package-branch= to their own branch for testing.

Once the package is available on MELPA, replace this block with =:ensure t= in
the use-package form below and remove the =package-vc-install= call.

#+begin_src emacs-lisp :tangle yes
(unless (package-installed-p 'gptel-agent-runtime)
  (package-vc-install
   `(gptel-agent-runtime
     :url "https://github.com/deno1011/gptel-agent-runtime"
     :branch ,my/gptel-agent-package-branch)))

;; Pull the configured package branch asynchronously at startup. This is
;; non-blocking and quiet if offline. Updated code becomes active from the next
;; Emacs session.
(when-let* ((lib (locate-library "gptel-agent-runtime"))
            (dir (file-name-directory lib)))
  (run-with-idle-timer
   10 nil
   (lambda (update-dir update-branch)
     (make-process
      :name "gptel-agent-runtime-update"
      :command (list "git" "-C" update-dir "pull" "--rebase" "--quiet"
                     "origin" update-branch)
      :noquery t
      :sentinel (lambda (proc _)
                  (when (and (not (process-live-p proc))
                             (zerop (process-exit-status proc)))
                    (message "gptel-agent-runtime: updated from %s — restart to apply"
                             update-branch)))))
   dir my/gptel-agent-package-branch))
#+end_src

* Runtime Configuration

The package configures:

- gptel providers and local backends
- active Ollama model detection, with Qwen fallback
- local-model directives
- web helpers
- response execution and inline image rendering hooks
- gptel tools
- workspace context
- experimental planner loop

#+begin_src emacs-lisp :tangle yes
(use-package gptel-agent-runtime
  :ensure nil
  :demand t
  :init
  (setq gptel-agent-runtime-default-local-model
        my/gptel-setup-default-ollama-model
        gptel-agent-runtime-default-local-model-label
        my/gptel-setup-default-ollama-label
        gptel-agent-runtime-prefer-active-ollama-model t
        gptel-agent-runtime-auto-start-ollama t)
  (when my/gptel-setup-ollama-models-directory
    (setq gptel-agent-runtime-ollama-models-directory
          my/gptel-setup-ollama-models-directory))
  :config
  (when (fboundp 'gptel-agent-runtime-use-default-local-model)
    (gptel-agent-runtime-use-default-local-model))
  (message "gptel-agent-runtime loaded from package; default local model is %s"
           my/gptel-setup-default-ollama-model))
#+end_src
