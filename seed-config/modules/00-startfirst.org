This config is an early load config for anything which need to be executed before anything else is loaded.

* Elpaca: treat =compat= as built-in (Emacs 30)

Elpaca's =elpaca.el= explicitly removes =compat= from its built-in
ignored list (=(delq 'compat ...)=). That was defensive — historically
compat was an ELPA-only package. Emacs 30 now ships compat as a true
built-in (=lisp/emacs-lisp/compat.el=). Without putting it BACK on the
ignored list, elpaca queues a build for compat, then byte-compilation
of dependents (magit, embark, doom-modeline, ...) loads the built-in
compat first, and elpaca's later activation step emits:

  Warning (emacs): compat loaded before Elpaca activation

This module loads BEFORE any module that has =:ensure t= forms, so
adding compat to =elpaca-ignored-dependencies= here takes effect before
elpaca's queue starts processing.

#+begin_src emacs-lisp :tangle yes
(with-eval-after-load 'elpaca
  (add-to-list 'elpaca-ignored-dependencies 'compat))
#+end_src

* Fullscreen Mode

This shall be started right at the beginning so that changing to full screen is immediate and doesnt get delayed while other configs are being loaded

#+begin_src emacs-lisp :tangle yes
;;; 00-fullscreen.el --- Fullscreen graphical frames early -*- lexical-binding: t; -*-

(defun my/fullscreen-frame (frame)
  "Put graphical FRAME into fullscreen."
  (when (and (frame-live-p frame)
             (display-graphic-p frame))
    (with-selected-frame frame
      (unless (memq (frame-parameter frame 'fullscreen)
                    '(fullscreen fullboth))
        (set-frame-parameter frame 'fullscreen 'fullboth)))))

(add-hook 'after-make-frame-functions #'my/fullscreen-frame)

(when (display-graphic-p)
  (my/fullscreen-frame (selected-frame)))
#+end_src
